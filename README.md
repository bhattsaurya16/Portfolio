# Saurya Bhatt — Portfolio

The source for my personal portfolio, built to present selected data science, analytics, and applied AI work.

**Live site:** [bhattsaurya16.github.io](https://bhattsaurya16.github.io/)

## Highlights

- Recruiter-focused one-page narrative
- Responsive design for desktop, tablet, and mobile
- Accessible navigation, focus states, and reduced-motion support
- Lightweight HTML, CSS, and JavaScript with no framework dependency
- Open Graph and X metadata for polished link previews

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.
